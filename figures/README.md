# Figures

Generated by `make_figures.py`.

```bash
python figures/make_figures.py
```

- `figure1_leadlag` : cross-correlation of each signal against the OFR Financial
  Stress Index, in levels and in first differences. **Computed directly from the
  released result files in `data/`, so it is reproducible from this repository
  alone.** It is the central evidence that Omega is a coincident state index
  rather than a leading indicator.
- `figure2_benchmarks` : out-of-sample F1 for Omega against the sharpened
  spectral baselines and the Absorption Ratio, each read raw and under the same
  persistence filter, rendering the values of §3.4. Regenerate the underlying
  numbers with `code/validation/samefilter_benchmarks.py`.
- `figure3_attribution` : attribution accuracy as the number of simultaneous
  epicentres varies with the spectral method held at fixed k, rendering the
  values of §3.6c.
